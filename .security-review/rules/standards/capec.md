# CAPEC Mapping

Use CAPEC to describe attacker patterns when useful for executive or threat-model reporting.

## Common Patterns

- CAPEC-1 Accessing Functionality Not Properly Constrained by ACLs
- CAPEC-31 Accessing/Intercepting/Modifying HTTP Cookies
- CAPEC-63 Cross-Site Scripting
- CAPEC-66 SQL Injection
- CAPEC-88 OS Command Injection
- CAPEC-111 JSON Hijacking
- CAPEC-115 Authentication Bypass
- CAPEC-126 Path Traversal
- CAPEC-137 Parameter Injection
- CAPEC-148 Content Spoofing
- CAPEC-153 Input Data Manipulation
- CAPEC-248 Command Injection
- CAPEC-272 Protocol Manipulation

## Usage

CAPEC is optional. Include it when it clarifies the attack scenario.

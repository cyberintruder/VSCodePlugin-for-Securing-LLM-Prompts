# NIST SSDF Mapping

Use NIST SSDF for secure software development and governance reporting.

## Relevant Practice Families

- PO: Prepare the Organization
- PS: Protect the Software
- PW: Produce Well-Secured Software
- RV: Respond to Vulnerabilities

## Review Applications

- Threat modeling and architecture review support PO and PW.
- Secrets management, provenance, build integrity, and artifact signing support PS.
- Secure coding, code review, and testing support PW.
- Fix validation, remediation tracking, and regression testing support RV.

## Usage

Map process gaps such as missing secure build controls, missing artifact integrity, or weak vulnerability response to NIST SSDF when the audience needs governance framing.

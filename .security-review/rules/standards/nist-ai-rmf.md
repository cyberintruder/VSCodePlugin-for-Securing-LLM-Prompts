# NIST AI RMF Mapping

Use NIST AI RMF for AI system governance, risk, and trustworthiness.

## Functions

- Govern
- Map
- Measure
- Manage

## Security Review Applications

Govern:

- Model, data, tool, and provider ownership.
- Policy for sensitive data and model use.

Map:

- AI actors, data sources, model dependencies, and external effects.

Measure:

- Prompt injection resistance, data leakage, unsafe tool use, and monitoring.

Manage:

- Guardrails, authorization, human approval, incident response, and continuous evaluation.

## Usage

Use this mapping for AI reviews involving regulated data, external model providers, autonomous agents, or high-impact decisions.
